# M9 notes

## Goal

Command palette + configurable keymap overlays.

## Command palette

- Shortcut: **`⌘⇧K`** (⌘⇧P remains theme cycle).
- Fuzzy/substring filter over a fixed catalog of actions.
- Enter runs the selected command; Esc closes.
- Also available from the palette itself ("Toggle Command Palette").

## Configurable keymap

Extra bindings layer on top of the built-in map via `settings.json`:

```json
{
  "key_bindings": [
    { "key": "cmd-alt-t", "action": "new_tab" },
    { "key": "cmd-shift-f", "action": "find", "context": "Terminal" }
  ]
}
```

### Action ids

| Action | Meaning |
|--------|---------|
| `new_tab` | New tab |
| `close_tab` / `close_pane` | Close active pane/tab |
| `next_tab` / `prev_tab` | Tab navigation |
| `split_right` / `split_down` | Splits |
| `open_settings` / `reload_settings` | Settings |
| `cycle_theme` | Theme cycle |
| `check_for_updates` | Update dialog |
| `find` / `find_next` / `find_prev` | Scrollback search |
| `toggle_command_palette` | Command palette |

Omit `context` to bind both `AppShell` and `Terminal`. Known contexts: `AppShell`, `Terminal`.

Reload the app after editing `key_bindings` (bindings are applied at startup).

## Implementation

| Piece | Location |
|-------|----------|

| UI + dispatch | `AppShell` |
