# M10 notes

## Goal

Ligatures, search-in-scrollback, and (deferred) per-pane fonts.

## Ligatures

Settings:

```json
{
  "terminal": {
    "font_family": "JetBrains Mono",
    "font_ligatures": true
  }
}
```

- Default remains **ligatures off** (`calt` disabled) for classic terminal fonts.
- When `font_ligatures` is true, font features use GPUI defaults (ligatures enabled if the font supports them).
- Requires a font that actually has ligatures (e.g. JetBrains Mono, Fira Code).

## Search in scrollback

| Key | Action |
|-----|--------|
| `⌘F` | Open find bar |
| `Enter` / `⌘G` | Next match |
| `⇧Enter` / `⌘⇧G` | Previous match |
| `Esc` | Close find (clears highlights) |

- Query is treated as a **literal** string (regex metacharacters escaped).
- Matches highlight in the grid; active match is selected and scrolled into view via the terminal backend.

## Per-pane fonts

**Deferred.** Font family/size remain window-global via `terminal.font_*` settings. Splitting panes still shares the same typeface.

## Implementation

| Piece | Location |
|-------|----------|
| `font_ligatures` setting | `sleipnir_settings` |
| Find bar + match activation | `AppShell` |
| Match highlight paint | `term_element.rs` |
