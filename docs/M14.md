# M14 notes

**Status:** shipped (detect-first)

## Goal

Light shell collaboration: prompt markers and long-running command awareness — **without** shipping a shell plugin suite.

## Scope

| Feature | Summary | Shortcut / setting |
|---------|---------|-------------------|
| OSC 133 detect | Scanner for `ESC ] 133 ; A/B/C/D ST` | automatic |
| Jump to prompt | Scroll to previous / next prompt marker | `⌘⇧↑` / `⌘⇧↓` |
| Notify on command finish | Unfocused + busy job ≥ N seconds → macOS notification | `notify_on_command_finish_secs` (default `5`; `0` off) |

## Shell integration

Enable OSC 133 in your shell (examples only — not auto-installed):

```bash
# zsh (example)
precmd()  { printf '\e]133;A\a' }
preexec() { printf '\e]133;B\a' }
```

Markers are also recorded when output is ingested via `write_output` (tests / display-only).

## Implementation

| Piece | Location |
|-------|----------|
| Pure scanner | `crates/terminal/src/osc133.rs` |
| Markers + jump + busy poll | `Terminal` methods |
| Notify | `osascript` display notification when window inactive |
