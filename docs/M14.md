# M14 notes

**Status:** planned (not implemented) — after M12 (M13 optional)

## Goal

Light shell collaboration: prompt markers and long-running command awareness — **without** shipping a shell plugin suite.

## Scope

| Feature | Summary |
|---------|---------|
| OSC 133 detect | Recognize prompt / command markers (detect-first; optional inject documented only) |
| Jump to prompt | Key bindings scroll to previous / next prompt in scrollback |
| Notify on command finish | If surface unfocused and command ran longer than N seconds → system notification |

## Non-goals

- Auto-install zsh plugins, Starship, autosuggestions (Kaku shell suite path)
- Built-in AI error recovery
- Full remote-control API
