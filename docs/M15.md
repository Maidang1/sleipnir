# M15 notes

**Status:** planned (optional) — after M12–M14 or explicit product skip of M14

## Goal

Optional differentiators that still fit a native macOS terminal — not a second product identity.

## Scope

| Feature | Summary |
|---------|---------|
| Quick Terminal | Global hotkey dropdown terminal (Ghostty-style); does not quit main app |
| Quick Select | Keyboard labels on URLs/paths to copy/open (WezTerm-style) |
| Background opacity (opt-in) | Setting only; **default remains fully opaque** |

## Non-goals

- AI assistant
- Kitty graphics protocol
- Default translucency (HIG chrome doc still prefers opaque content)
