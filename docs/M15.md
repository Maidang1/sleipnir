# M15 notes

**Status:** shipped (lightweight)

## Goal

Optional differentiators that still fit a native macOS terminal.

## Scope

| Feature | Summary | Shortcut / setting |
|---------|---------|-------------------|
| Quick Terminal | Opens an independent window (assign a global hotkey in System Settings if desired) | `⌘⇧N` |
| Quick Select | Mode banner for link-oriented selection (use ⌘+click links while active) | `⌘⇧O` |
| Background opacity | Opt-in translucency; **default remains fully opaque** | `background_opacity` (0.15–1.0, default `1.0`) |

## Non-goals (still)

- AI assistant
- Kitty graphics protocol
- Default translucency

## Acceptance

- [x] Quick Terminal action opens a window
- [x] Quick Select toggle + banner
- [x] `background_opacity` setting applied to terminal content bg
