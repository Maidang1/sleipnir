# M11 notes

**Status:** shipped

## Goal

Native-feeling visual polish on the terminal paint layer — without changing tab, session, or settings architecture.

## Scope

| Item | Summary |
|------|---------|
| Cursor fade blink | Ease-in-out opacity (~530ms half-period); solid while typing; respects `terminal.blinking` |
| URL / link hover | Underline + pointing-hand cursor for hyperlinks under the pointer (⌘+hover) |
| Scroll momentum | Uses platform trackpad momentum events (no extra code path required) |

## Behavior

### Cursor blink

| `terminal.blinking` | Behavior |
|---------------------|----------|
| `off` | Always solid |
| `on` | Always animate (after short solid window post-keystroke) |
| `terminal_controlled` | Animate only when the app enables blink (DECSCUSR) |

Pure helper: `cursor_blink_alpha` in `crates/sleipnir_ui/src/blink.rs`.

### URL hover

Backend already sets `last_hovered_word` on ⌘+mousemove. UI paints a theme-blue underline and switches to `PointingHand`.

## Implementation

| Piece | Location |
|-------|----------|
| Blink math + tests | `crates/sleipnir_ui/src/blink.rs` |
| Blink state on TermView | `sleipnir_ui.rs` (`last_input_at`, `terminal_wants_blink`) |
| Cursor / hover paint | `term_element.rs` |
