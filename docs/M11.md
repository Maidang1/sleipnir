# M11 notes

**Status:** planned (not implemented)

## Goal

Native-feeling visual polish on the terminal paint layer — without changing tab, session, or settings architecture.

## Scope

| Item | Summary |
|------|---------|
| Cursor fade blink | Ease-in-out opacity (~530ms half-period); solid while typing; respects `terminal.blinking` |
| URL / link hover | Underline (and optional preview later) for hyperlinks under the pointer |
| Scroll momentum | Optional macOS-like wheel coast; drop if janky |

## Non-goals

- Pane layout, PTY, keymap catalog, multi-window
- Background blur / transparency (product default stays opaque)

## Design

Full design: [`docs/superpowers/specs/2025-01-20-m11-visual-polish-design.md`](superpowers/specs/2025-01-20-m11-visual-polish-design.md)
