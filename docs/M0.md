# M0 notes

## Goal

Empty GPUI window via `cargo run -p jiajia_term`.

## Requirements

- Rust **1.95.0** (`rust-toolchain.toml`)
- macOS + Xcode Metal Toolchain:
  `xcodebuild -downloadComponent MetalToolchain`
- Workspace crates copied from Zed (Apache-2.0 GPUI stack)

## Run

```bash
cd ~/codes/jiajia-term
cargo run -p jiajia_term
```
