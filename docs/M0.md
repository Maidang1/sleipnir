# M0 notes

## Goal

Empty GPUI window via `cargo run -p harbor`.

## Requirements

- Rust **1.95.0** (`rust-toolchain.toml`)
- macOS + Xcode Metal Toolchain:
  `xcodebuild -downloadComponent MetalToolchain`
- Workspace crates copied from Zed (Apache-2.0 GPUI stack)
- **`font-kit` feature** on `gpui` / `gpui_macos` / `gpui_platform`
  (otherwise macOS uses `NoopTextSystem` and all text is blank)

## Run

```bash
cd ~/codes/harbor
cargo run -p harbor
```
