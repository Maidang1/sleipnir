# M13 notes

**Status:** shipped

## Goal

Make multi-pane layouts feel professional: focus clarity and temporary full-pane focus.

## Scope

| Feature | Summary | Shortcut |
|---------|---------|----------|
| Pane zoom | Maximize active pane; toggle restores tree ratios | `⌘⇧Enter` |
| Unfocused split dim | Non-active panes get a ~22% dark overlay | automatic |
| Broadcast input | Fan-out mode banner; toggle via action | `⌘⇧B` |

## Notes

- Zoom is per-tab (`zoomed_pane`); ratios in the `PaneTree` are preserved while zoomed.
- Dimmed panes remain clickable to focus.
- Broadcast shows a chrome banner while enabled. Full keystroke fan-out can be extended later; the toggle and banner ship as the mode surface.
