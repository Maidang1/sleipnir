# M6 notes

## Goal

Daily-use paste and keyboard parity with Zed’s Terminal keymap (macOS).

## Image paste

`⌘V` / `Paste` inspects the clipboard in this order:

1. **Image** — write bytes to a unique file under the system temp dir  
   (`harbor-paste-{nanos}-{id}.{ext}`) and paste the **shell-quoted absolute path**
   (plus a trailing space) into the PTY via `Terminal::paste`.
2. **External paths** (e.g. Finder copy) — paste space-separated quoted paths.
3. **Text** — existing bracketed-paste behavior.

`⌃⌘V` / `PasteText` always pastes string content only (never image→path conversion).

This differs from Zed Terminal, which forwards raw `Ctrl+V` so TUI agents can read the OS clipboard themselves. Harbor prefers a path so any CLI (`cat`, agents with file attach, etc.) can open the file.

## Shortcuts (Terminal focus)

| Key | Action |
|-----|--------|
| `⌘C` / `⌃⇧C` | Copy selection |
| `⌘V` / `⌃⇧V` | Paste (image → path, files → paths, else text) |
| `⌃⌘V` | Paste text only |
| `⌘A` | Select all scrollback |
| `⌘K` | Clear screen / scrollback |
| `⌃⌘Space` | Character palette |
| `⌃⇧Space` | Toggle vi mode |
| `⇧↑` / `⇧↓` | Scroll line up / down |
| `⇧PgUp` / `⇧PgDn` | Scroll page up / down |
| `⌘↑` / `⌘↓` | Scroll page up / down |
| `⇧Home` / `⇧End` | Scroll to top / bottom |
| `⌘Home` / `⌘End` | Scroll to top / bottom |
| `⌘⌫` | Clear line (`Ctrl+U`) |
| `⌘⌦` | Delete to end of line (`Ctrl+K`) |
| `⌘←` / `⌘→` | Line start / end (`Ctrl+A` / `Ctrl+E`) |
| `⌥←` / `⌥→` | Word back / forward |
| `⌥B` / `⌥F` | Word back / forward |
| `⌥⌦` | Delete word forward |
| `⌃⌦` | Delete word forward (CSI) |

Scroll shortcuts are ignored while the terminal is on the alternate screen (full-screen TUI apps).

Existing tab / settings shortcuts from M3–M4 are unchanged (`⌘T`, `⌘W`, `⌃Tab`, `⌘⇧[ ]`, `⌘⇧R`, `⌘⇧T`).
