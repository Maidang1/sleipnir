# M2 notes

## Goal

Local interactive shell over a real PTY, with keyboard/IME, selection, copy/paste, and scroll.

## Behavior

- `TermView::new_local` → `TerminalBuilder::new` (async) → shell PTY
- Keys: special/control via `try_keystroke`; printable via IME `InputHandler`
- Mouse: select / drag; scroll wheel
- Clipboard: `cmd-c` / `cmd-v` (and ctrl-shift-c/v) in `Terminal` key context

## Run

```bash
cargo run -p jiajia_term
```

Type in the window; shell should respond.
