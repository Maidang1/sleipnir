# M4 notes

## Goal

Settings/theme polish suitable for daily use.

## Settings file

Path: `~/.config/jiajia-term/settings.json`  
Schema-compatible subset of Zed `terminal.*` keys. See `docs/settings.example.json`.

### Keys

| Key | Notes |
|-----|--------|
| `theme` | `mocha` \| `macchiato` \| `frappe` \| `latte` |
| `terminal.font_size` | number (px) |
| `terminal.font_family` | string |
| `terminal.line_height` | number |
| `terminal.cursor_shape` | `block` \| `underline` \| `bar` \| `hollow` |
| `terminal.option_as_meta` | bool |
| `terminal.copy_on_select` | bool |
| `terminal.max_scroll_history_lines` | number |
| `terminal.scroll_multiplier` | number |
| `terminal.minimum_contrast` | number |

## Shortcuts

| Key | Action |
|-----|--------|
| `⌘⇧R` | Reload settings from disk |
| `⌘⇧T` | Cycle theme (session only) |

## Release

```bash
cargo build -p jiajia_term --release
./target/release/jiajia-term
```
