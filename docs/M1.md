# M1 notes

## Goal

Display-only terminal: inject ANSI via `write_output` and paint a batched monospaced grid.

## Crates

- `jiajia_settings` — schema-compatible terminal settings + palette; `~/.config/jiajia-term/settings.json`
- `terminal` — copied from Zed, rewired off full `settings`/`theme`/`task`
- `task_types` / `release_channel` — minimal stubs
- `jiajia_term_ui` — `TermView` + `TermElement` (batch `shape_line`)

## Run

```bash
cargo run -p jiajia_term
```

You should see colored ANSI sample text (truecolor + 16-color).
