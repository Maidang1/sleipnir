# M12 notes

**Status:** shipped

## Goal

Close daily-use gaps versus Kaku / Kitty / Ghostty while keeping Sleipnir a clean macOS terminal (no AI, no shell-suite installer).

## Scope

| # | Feature | User-facing result |
|---|---------|-------------------|
| 1 | Font zoom | `⌘+` / `⌘=` / `⌘-` / `⌘0` adjust size at runtime (window-scoped override; not persisted by default) |
| 2 | New OS window | `⌘N` opens an independent window |
| 3 | Close confirm | Closing pane/tab with a foreground job prompts once |
| 4 | Path open | Cmd-click path-like targets (`file.rs:12`, absolute/relative paths) |
| 5 | Bell | `terminal.bell`: `off` \| `system` \| `visual` actually works |
| 6 | copy_on_select UX | Toggle visible in settings UI + docs (default remains `false`) |

## Settings

```json
{
  "confirm_close": "dirty",
  "path_links": true,
  "terminal": {
    "bell": "visual",
    "copy_on_select": false
  }
}
```

| Key | Values | Default | Meaning |
|-----|--------|---------|---------|
| `confirm_close` | `dirty` \| `always` \| `never` | `dirty` | Confirm close when a non-shell foreground job is running |
| `path_links` | bool | `true` | Open path-like navigation targets |
| `terminal.bell` | `off` \| `system` \| `visual` | `off` | System beep and/or tab flash |
| `terminal.copy_on_select` | bool | `false` | Copy selection on mouse-up; toggle in Settings → General |

**Dirty policy:** idle interactive shell alone is **not** dirty; a foreground job (`sleep`, `npm`, `vim`, …) is dirty (foreground process group ≠ shell child).

**Multi-window session:** each window has its own tabs/panes. Session restore remains last-window-wins (not multi-window restore).

**Font zoom:** window-scoped only; not written to `settings.json`. Reload settings (`⌘⇧R`) clears the override.

## Shortcuts

| Key | Action |
|-----|--------|
| `⌘+` / `⌘=` | Increase font size |
| `⌘-` | Decrease font size |
| `⌘0` | Reset font size to settings |
| `⌘N` | New window |

Also in **View** menu (font zoom) and **Shell** / **Window** menus (New Window), plus the command palette.

## Non-goals (M12)

- Pane zoom, unfocused split dim, broadcast (→ M13)
- Shell integration / OSC 133 / command-finish notify (→ M14)
- Quick Terminal, Quick Select (→ M15)
- Changing default `copy_on_select` to `true`
- Multi-window session restore
