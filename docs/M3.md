# M3 notes

## Goal

Multi-tab shell + open web URLs from the terminal.

## Tabs

- `AppShell` owns `Vec<Tab>` of `Entity<TermView>`
- UI: tab bar with titles, click to switch, `+` new tab
- Shortcuts (while focused in terminal):
  - `⌘T` new tab
  - `⌘W` close tab (always keeps ≥1)
  - `⌘⇧]` / `⌃Tab` next
  - `⌘⇧[` / `⌃⇧Tab` prev

## URLs

- Terminal hyperlink click emits `Event::Open`
- `TermView` opens only `http(s)://`, `mailto:`, `ftp://` via `cx.open_url`
- Path-like targets ignored (P0/M3 scope)

## Run

```bash
cargo run -p harbor
```

Print a URL in the shell and cmd-click / click with secondary modifier if mouse mode allows; OSC/regex hyperlinks open in the browser.
