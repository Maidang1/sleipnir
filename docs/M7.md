# M7 notes

## Goal

Signed & notarized release builds + in-app auto-update from GitHub Releases.

## Status: complete (software)

| Piece | Status |
|-------|--------|
| Auto-update (`updater` crate) | ✅ Check / download / SHA-256 verify / restart install |
| Update UI (`⌘⇧U`, modal dialog) | ✅ Manual check only (no launch-time poll) |

| Integrity | ✅ Release artifacts include `*.zip.sha256` sidecar |

## Ops notes

- Without Apple Developer cert secrets, CI falls back to **ad-hoc** signing. Gatekeeper will warn; users can right-click → Open.
- With `CODE_SIGNING_CERT_P12` + notarization secrets, the same workflow signs and notarizes.
- Auto-update only runs when the user chooses **Check for Updates…** (`⌘⇧U`).
