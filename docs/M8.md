# M8 notes

## Goal

Session persistence: restore tabs, splits, and per-pane working directories on launch.

## Behavior

- On quit (and after structural layout changes), write `~/.config/sleipnir/session.json`.
- On launch, if `restore_session` is true (default), rebuild the last tab tree.
- Each leaf pane is respawned with the last known **cwd** when that directory still exists.
- Custom tab titles are restored.
- Scrollback content and running processes are **not** restored (fresh PTY each time).

## Schema (`session.json`)

```json
{
  "version": 1,
  "active_tab": 0,
  "tabs": [
    {
      "custom_title": "work",
      "active_pane": 2,
      "tree": {
        "type": "split",
        "axis": "horizontal",
        "ratio": 0.5,
        "first": { "type": "leaf", "id": 1, "cwd": "/Users/you/src" },
        "second": { "type": "leaf", "id": 2, "cwd": "/Users/you" }
      }
    }
  ]
}
```

## Settings

| Key | Default | Meaning |
|-----|---------|---------|
| `restore_session` | `true` | Load `session.json` on launch; keep writing it |

```json
{
  "restore_session": true
}
```

## Implementation

| Piece | Location |
|-------|----------|
| Pure snapshot I/O + tests | `crates/sleipnir_ui/src/session.rs` |
| Snapshot / restore / quit hook | `AppShell` in `app_shell.rs` |
| Spawn with cwd | `TermView::new_local_in_shell(..., cwd, ...)` |

## Verify

1. Open 2 tabs, split one pane, `cd` into a project.
2. Quit with `⌘Q`.
3. Relaunch — same tabs/splits, shells start in the previous directories.
4. Set `"restore_session": false` — launch opens a single home tab.
